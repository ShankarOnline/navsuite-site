What it is
"

Your whole network and every disk, in one window

The built-in "network neighbourhood" has quietly broken down — SMB1 is gone, each operating system uses a different discovery method, and mesh VPNs like Tailscale don't carry Bonjour. Narada joins the pieces back together: it finds a system through every channel it can, shows it as one record, and lets you open it with whichever protocol fits — browse its shares, open SSH, print to it, or play a file off it. Drives from another operating system open safely, read-only.

Four pieces, one app

The products, and what's new about each

Each piece stands on its own and shares one Rust core; together they do what none can alone.

NetworkNetNav

Every system on your home network and tailnet as one record, in a section per channel, with every way in one click away.

NoveltyScanners stop at IP, MAC and open ports, and each OS's network view uses one half-blind protocol. NetNav merges every channel into one record and makes each one usable, not just listed.
FilesFileNav

Local disks, SMB, SFTP and FTP in one view that never freezes on an offline share.

NoveltyThe strong file managers are tied to one OS, and checking a copy is exact means hunting a setting or a second tool. FileNav treats every location alike and makes a verified, resumable copy the normal case.
PhonesDrop

AirDrop-style passing between any phones and computers, joined by a QR code. No app on the phone.

NoveltyAirDrop–Quick Share only works on supported hardware, and app-based tools need installing on every device. Drop runs on your own computer with no internet, holds a file for a phone that isn't open yet, and checks it with SHA-256.
WatchGuard

What joined your network, what's about to drop off the tailnet, and which server needs attention.

NoveltyTailscale manages the tailnet but not what each peer offers; Pi-hole names clients by IP. Guard joins them on one record per device, so an alert leads straight to what the device is and shares.
All of itNarada

One window, one tree, one transfer queue, one terminal.

NoveltyA system hidden from one channel is still found and used through another — a Pi missing from NetBIOS shows under Bonjour and SSH; the NAS Bonjour can't see across the tailnet shows under Tailscale. Your copies can share the map between your machines, never the passwords.
In the first build

Working today

One record per system

Merged across ARP, a port sweep, Bonjour/Avahi, NetBIOS, SSDP and Tailscale — with your own labels.

Verified, resumable copies

A copy preview, one queue with pause and resume, and a SHA-256 check on every file.

Drives & dual boot

Every partition listed; the other operating system opens read-only, always. Mount and safe eject, and a built-in ext4 reader.

Play media and music

Video and music play in the window and seek from anywhere, with tags and cover art.

Phone drop page

Scan a QR code and send files phone-to-phone through a computer — nothing to install.

Terminal & probes

A built-in terminal in the shell you choose, plus ping, traceroute, port, DNS and HTTP checks with no admin rights.

Where our leads come from

The tools we studied

We took the best idea from each of these and asked what a single, cross-platform, open tool would do instead. None of their code is used; they're the direction-setters.

Network scanners

Fast sweeps and device recognition — but shallow on services, single-subnet, and often one-OS or cloud-tied.

Advanced IP Scanner · Angry IP Scanner · Fing · nmap

File managers

Powerful dual-pane and scripting — but each tied to one operating system, weak on SFTP and offline shares.

Directory Opus · Total Commander · Explorer · Finder · GNOME Files

Local file sharing

Great peer-to-peer sharing — but needs an app on every device, or both browsers open at once.

LocalSend · PairDrop · AirDrop · Quick Share

Mesh VPN & DNS

The connectivity and the filtering we build on — but neither shows what a device is or shares.

Tailscale · Pi-hole

Remote screens

Browser-based remote access done right underneath — the open path to the same result on every system.

Raspberry Pi Connect (approach) · RustDesk (engine)

Media players

Streaming and seeking from anywhere, inside the file browser rather than a separate app.

VLC · Plex

How it's built

Native, and honest about safety

Read-only where it matters. Narada never writes to another operating system's partitions or to a raw device — they open read-only. It does not disable, evade or work around antivirus software; that's how malware behaves. Sign-ins stay in your operating system's keychain and never leave the machine.
One Rust codebase. Built with Rust and Tauri — small native apps on every desktop, no browser runtime bundled.
